# 使用说明

版本：**1.0.0**。

## 连接与组件

进入游戏关卡后点击 **连接游戏**。需要原生功能时，先退出游戏，在 **设置 → 安装 / 更新全部组件** 安装收集、战斗、装备回收组件，再重启游戏并连接。

程序自动识别安装目录；无法识别时可手动选择，Xbox 安装目录及其 `Content` 子目录均可使用。缺少 Blueprint Loader 时，按提示打开作者下载页并完成下载，或选择已有 ZIP。安装器会备份被替换的文件。

**F8** 开始或暂停，**F9** 停止所有功能。配置保存在 `%LOCALAPPDATA%\MinecraftDungeons2Toolbox`。

## 自动恢复

设置血量阈值和法器槽位。程序检查法器冷却、充能和灵魂；药水作为备用。取消所有法器槽位后只使用药水。

## 附近交互

开启 **自动拾取与交互**，选择宝箱、装备 / 书 / TNT、食物或绿宝石罐。仅处理原生交互范围内的目标，不自动追赶。

通用间隔默认 500 ms，食物默认 1000 ms，可设置为 100–30000 ms。开启允许移动时交互，可边跑边拾取。散落的绿宝石由游戏拾取。

## 自动战斗

开启 **遇到敌人自动攻击**，攻击附近敌人。判定范围为 80–500 游戏单位，默认 220；实际命中范围由武器决定。

攻击预警和提前使用法器位于自动战斗页，使用自动恢复页选中的法器槽位。药水仍遵循血量阈值。自动闪避依赖闪避充能、威胁方向和地面状态。

## 组合、跳劈与右键闪避

在 **设置 → 配置组合、跳劈和右键闪避** 配置辅助操作。

- 法器组合默认 G，可独立选择组合槽位，与自动恢复的槽位选择独立。
- 右键闪避使用游戏当前闪避键位，Shift + 右键保留远程攻击。
- Xbox 手柄可配置按钮或组合绑定；键鼠与手柄设置独立保存。

## 装备整理（实验）

选择品质、类型和保护条件后，先预览处理清单，再开启整理。锁定、收藏、当前装备和符合保护条件的物品会保留。整理已有装备与新拾取装备分别操作。

## 后台运行

**游戏后台运行** 默认开启，已选自动功能在切出游戏后继续执行。关闭后，自动恢复、战斗和交互等待游戏返回前台。游戏需要处于可操作关卡。

## 日志

点击 **导出日志** 可保存配置和最近动作。反馈问题时提供平台、游戏版本和复现步骤；日志由用户自行分享。
