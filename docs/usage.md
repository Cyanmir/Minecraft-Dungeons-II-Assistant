# MCD2A 使用说明

版本：**1.0.0**。

## 首次运行

解压发行包并运行 `MCD2A.exe`，进入游戏关卡后点击 **连接游戏**。配置功能与键位后，使用 **F8** 开始 / 暂停，**F9** 停止。附近交互、战斗与装备整理按需要开启。

自动恢复的血量阈值、法器槽位、药水备用判断槽位分别保存。三个法器都未勾选时，只尝试已就绪的药水；勾选法器后按冷却与灵魂读数判断。法器组合使用独立的槽位勾选。

## 组件安装与升级

1. 保存进度并完全退出游戏，停止旧工具。
2. 在自动战斗页点击 **安装 / 更新直接收集组件** 与 **安装 / 更新原生战斗组件**。
3. 工具自动识别游戏目录；存在多个匹配或无法识别时，选择实际安装目录。Xbox 安装外层目录及其 `Content` 子目录均可识别。
4. 若缺少 Blueprint Loader，按窗口提示到作者官网完成下载，或选择已有的完整 ZIP。已有完整加载器可继续使用。
5. 重启进入关卡后重新连接。

当前收集协议 **6**、战斗协议 **4**。旧版两个组件都需更新；保留原有装备回收组件。安装器将备份被替换文件，并拒绝游戏运行时写入。

## 附近交互

开启 **附近原生交互（实验）** 与所需目标类型。支持已有宝箱、装备 / TNT / 附魔书、已识别食物，以及小型 / 大型绿宝石罐。

通用间隔默认 **500 ms**，食物间隔默认 **1000 ms**。滑块与数字框同步，范围 **100–30000 ms**。允许手动移动时交互开关控制是否可以边跑边交互；工具不会自动寻路、移动鼠标或选中目标。

游戏仍决定原生范围、拾取归属、食物效果、宝箱掉落与罐子破坏结果。实体消失、请求发出或能力激活不单独代表结果已确认。绿宝石散落后由游戏原生规则拾取。

## 自动战斗

原生模式下开启 **遇到敌人自动攻击**，尝试攻击附近敌人。判定范围可调整，不自动追赶远处敌人。持有 TNT 时保留原有近战保护条件。

**攻击预警** 与 **战斗提前使用法器** 位于自动战斗页。法器使用自动法器页选中的槽位，继续检查冷却与灵魂；药水受血量阈值限制。蓄力、持续引导和瞄准法器使用已适配的原生生命周期，未确认效果的结果会保留为未确认。

实验性自动闪避依赖有效的充能、威胁方向与地面读数。功能是否生效以实际动作及日志为准。

## 手柄与辅助按键

支持 Xbox 手柄的按钮 / 组合绑定，键鼠与手柄设置独立保存。手柄模式下可使用原生附近交互；跳劈辅助和右键闪避仍按键鼠方式工作。

法器组合默认 **G**。开启右键闪避后，请核对游戏内定向闪避键，默认 **R**；**Shift + 右键** 保留远程攻击操作。修改设置后重新按 F8 开始。

## 装备整理

先生成预览清单，检查类别、品质与保护规则，再开启需要的整理范围。装备消失不代表已出售，回收数量以游戏组件回执为准。已有预编译回收组件保留，GDK 回收尚未验证。

公开包使用界面标签和物品类型名称显示清单。可将自己已有的 `equipment-presentation.bin.gz` 放在 EXE 同级目录加载原版展示资源；此本地文件不属于公开发行包。

## 平台与反馈

Steam 已有部分目标的实测或人工确认。GDK 当前为特定已采集包的实验适配，完整固定请求槽及实际游戏动作待实机验证。不要把通信握手或编译成功当成效果已成功。

异常时导出日志，并提供平台、游戏版本、功能设置与复现步骤。配置和日志沿用 `%LOCALAPPDATA%\MinecraftDungeons2Toolbox`，以兼容旧版设置；日志不会自动上传。
